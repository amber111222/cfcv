# Решатель Тестов и Контрольных Работ (Фоновый DeepSeek) 📱🧠

Android-приложение на **Jetpack Compose** для мгновенного решения школьных и университетских тестов, проверочных и контрольных работ по фото с помощью **DeepSeek**.

> ⚡ **Фоновая отправка в DeepSeek и готовые ответы прямо в приложении! Без API ключей Gemini.**

---

## 🚀 Основные возможности

* **Фоновый режим работы с DeepSeek:**
  * Запрос отправляется в DeepSeek в фоновом режиме, а готовые ответы выводятся **прямо на экран приложения** без необходимости ручного копирования туда-сюда.
* **Готовые разделы с русскими промптами:**
  * ⚡ **Только ответы** — краткие готовые ответы (`№1: В`, `№2: 42`, `№3: А, Г`) для быстрого списывания или сверки.
  * 💡 **Краткое пояснение** — точный ответ плюс 1–2 предложения с аргументацией.
  * 📚 **Полное решение** — пошаговый разбор с формулами, ходом рассуждений и вычислениями.
  * 🔢 **Тест (А, Б, В, Г)** — для тестов с выбором одного или нескольких вариантов.
  * ✍️ **Свой запрос** — просмотр и редактирование промпта перед отправкой.
* **Съемка и выбор фото:**
  * 📸 **Камера** — полноразмерная съемка теста с коррекцией поворота (Exif).
  * 🖼️ **Галерея** — загрузка любого фото или скриншота.
  * ✍️ **Поле для ввода/редактирования текста заданий**.
* **Два режима подключения к DeepSeek:**
  1. **Бесплатный режим через установленный DeepSeek:** фото и промпт автоматически передаются в DeepSeek, а скопированный ответ приложение перехватывает и выводит на экран само.
  2. **100% фоновый режим по API:** при указании ключа DeepSeek в настройках ⚙️ ответы приходят напрямую в приложение за 2 секунды вообще без открытия сторонних окон.

## 📖 Как пользоваться

1. Сфотографируйте тест или выберите фото из галереи.
2. Выберите нужный раздел (например, ⚡ **«Только ответы»**).
3. Нажмите кнопку **«РЕШИТЬ ЧЕРЕЗ DEEPSEEK»**.
4. Получите готовые ответы прямо в приложении с возможностью скопировать в один клик!
