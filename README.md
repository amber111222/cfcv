# Решатель Тестов и Контрольных Работ (Keyless Background Edition) 📱🧠

Android-приложение на **Jetpack Compose** для мгновенного решения школьных и университетских тестов, проверочных и контрольных работ по фото с помощью **DeepSeek**.

> ⚡ **БЕЗ API КЛЮЧЕЙ И ПОЛНОСТЬЮ В ФОНЕ! Ответы сразу в приложении!**

---

## 🚀 Как это работает БЕЗ API ключей и в фоне:

* **Встроенный фоновый движок DeepSeek (`DeepSeekWebSolver`):**
  * При нажатии на кнопку **«⚡ РЕШИТЬ ФОНОВО ЧЕРЕЗ DEEPSEEK»** приложение само в фоне передает ваш запрос и русский промпт в DeepSeek.
  * DeepSeek генерирует ответ, и приложение **автоматически выводит готовый ответ прямо на экран**.
  * **Не нужно никаких API ключей**, никаких подписок и никаких настроек!
  * **Не нужно вручную переключаться между приложениями и копировать туда-сюда!**
* **Промпты для каждого раздела:**
  * ⚡ **Только ответы** — номера и буквы/числа (`№1: В`, `№2: 42`, `№3: А, Г`) для мгновенного списывания.
  * 💡 **Краткое пояснение** — точный ответ плюс 1–2 предложения с аргументацией.
  * 📚 **Полное решение** — пошаговый разбор с формулами и вычислениями.
  * 🔢 **Тест (А, Б, В, Г)** — для тестов с выбором одного или нескольких вариантов.
  * ✍️ **Свой запрос** — просмотр и редактирование промпта перед отправкой.
* **Съемка и выбор фото:**
  * 📸 **Камера** — полноразмерная съемка теста с коррекцией поворота (Exif).
  * 🖼️ **Галерея** — загрузка любого фото или скриншота.
  * ✍️ **Поле ввода текста заданий** (необязательно, если есть фото).
* **Удобство:**
  * Кнопка **«Копировать»** в один клик переносит весь ответ в буфер обмена телефона.

## 📖 Инструкция по использованию

1. Откройте приложение, сфотографируйте тест (или выберите из галереи).
2. Выберите нужный раздел (например, ⚡ **«Только ответы»**).
3. Нажмите **«⚡ РЕШИТЬ ФОНОВО ЧЕРЕЗ DEEPSEEK»**.
4. При первом запуске в раскрывающемся окне войдите в свой аккаунт DeepSeek один раз. После входа все запросы выполняются автоматически в фоновом режиме, а ответы сразу выводятся на экран!
