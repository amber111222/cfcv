# Решатель Тестов и Контрольных Работ (Test & Exam Solver AI) 📱🧠

Android-приложение на **Jetpack Compose**, которое позволяет сфотографировать тест, проверочную или контрольную работу (включая русский печатный и рукописный текст), распознает задания и мгновенно присылает готовый точный ответ.

---

## 🚀 Основные возможности

* **Распознавание русского языка (OCR + Vision):**
  * Построено на передовой мультимодальной нейросети **Google Gemini Vision** (по умолчанию `gemini-2.5-flash`), способной считывать сложный русский текст, рукописные заметки, математические/химические формулы, дроби и таблицы.
* **Съёмка и выбор фото:**
  * 📸 **Камера** — полноразмерная съемка заданий с автоматическим выравниванием ориентации (Exif).
  * 🖼️ **Галерея** — загрузка готовых фотографий и скриншотов.
* **3 режима решения:**
  * ⚡ **Только ответы** — мгновенный список правильных вариантов (`№1: В`, `№2: 42`, `№3: А, Г`) для быстрой проверки.
  * 💡 **Ответ с кратким пояснением** — точный ответ плюс 1–2 предложения с аргументацией.
  * 📚 **Полное пошаговое решение** — подробный ход рассуждений, формулы и промежуточные вычисления.
* **Уточнение задания:**
  * Возможность дописать инструкции для ИИ (например: *«Реши вариант 2, только чётные номера»*).
* **Быстрое копирование:**
  * Кнопка **«Копировать»** в один клик переносит весь ответ в буфер обмена.
* **Настройки API:**
  * Встроенное окно настроек для ввода бесплатного Gemini API ключа и выбора модели (`gemini-2.5-flash`, `gemini-2.0-flash`, `gemini-1.5-flash`).

## 🛠️ Стек технологий

* **Язык:** Kotlin 2.2+
* **UI:** Jetpack Compose (Material 3)
* **Архитектура:** Clean Architecture / MVVM, Coroutines, StateFlow
* **Сеть & AI:** OkHttp, Gemini Multimodal REST API, Firebase AI
* **Обработка фото:** Android FileProvider, ExifInterface
* **Target SDK:** Android 15 / 16 (API 36), Min SDK: Android 7.0 (API 24)

---

## 🔑 Настройка API ключа

1. Перейдите на [Google AI Studio](https://aistudio.google.com/apikey) и создайте бесплатный API ключ.
2. Откройте приложение, нажмите **⚙️ (Настройки)** в правом верхнем углу.
3. Вставьте ключ и нажмите **«Сохранить»**.
