# Решатель Тестов и Контрольных Работ (DeepSeek Edition) 📱🧠

Android-приложение на **Jetpack Compose** для мгновенного решения школьных и университетских тестов, проверочных и контрольных работ по фото с помощью **DeepSeek**.

> ⚡ **Работает без API ключей Gemini и без сложных настроек!**

---

## 🚀 Основные возможности

* **Прямая интеграция с приложением DeepSeek:**
  * Передает снимок теста и русский промпт прямо в мобильное приложение **DeepSeek** (`com.deepseek.chat`) или браузер.
* **Автоматический возврат ответа в приложение:**
  * Когда вы копируете ответ в DeepSeek и возвращаетесь в приложение, оно **автоматически подхватывает готовый ответ** из буфера обмена и выводит его в структурированном виде!
* **Готовые разделы с русскими промптами:**
  * ⚡ **Только ответы** — промпт для получения списка ответов (`№1: В`, `№2: 42`, `№3: А, Г`) без лишней воды.
  * 💡 **Краткое пояснение** — промпт для получения точного ответа с кратким объяснением в 1–2 предложения.
  * 📚 **Полное решение** — пошаговый разбор с формулами, ходом рассуждений и вычислениями.
  * 🔢 **Тест (А, Б, В, Г)** — специализированный формат для тестов с вариантами выбора.
  * ✍️ **Свой запрос** — возможность посмотреть и отредактировать любой промпт перед отправкой.
* **Съемка и выбор фото:**
  * 📸 **Камера** — полноразмерная съемка теста с коррекцией поворота (Exif).
  * 🖼️ **Галерея** — загрузка любого фото или скриншота.
* **Быстрое копирование:**
  * Кнопка **«Копировать»** в один клик переносит весь ответ в буфер обмена телефона.

## 📖 Как пользоваться

1. Сделайте фото теста или контрольной работы (или выберите из галереи).
2. Выберите нужный раздел (например, ⚡ **«Только ответы»**).
3. Нажмите **«ОТПРАВИТЬ В ПРИЛОЖЕНИЕ DEEPSEEK»**.
4. В открывшемся DeepSeek отправьте фото с промптом и скопируйте полученный ответ.
5. Переключитесь обратно в приложение — ответ появится на экране автоматически!
